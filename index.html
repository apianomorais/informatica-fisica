Três ferramentas, um só fluxo de trabalho

Um experimento de laboratório produz uma tabela de medidas. Essa tabela precisa ser organizada, as incertezas precisam ser propagadas, um ajuste precisa ser feito, um gráfico precisa ser desenhado e tudo isso precisa chegar a outra pessoa na forma de um relatório que ela consiga ler. Nenhuma dessas etapas é física, e todas elas tomam tempo de quem faz física.

Esta disciplina trata das três ferramentas que dão conta delas. A planilha organiza e explora os dados com rapidez e sem programar. O LaTeX compõe o texto científico, com equações, figuras numeradas e bibliografia que se mantêm coerentes sozinhas. E o Python automatiza o que se repete, calcula o que a planilha não alcança e produz gráficos em qualidade de publicação.

As três não competem entre si: elas se encaixam. O curso termina com um trabalho em que os dados saem de uma planilha, passam por um programa em Python e chegam a um relatório em LaTeX, que é exatamente o caminho que um artigo de física percorre.

Como usar este material

Cada aula é uma página só, com os códigos prontos para copiar. O botão copiar no canto de cada bloco põe o programa na área de transferência, de onde ele vai direto para o Spyder. Os programas são para serem rodados, quebrados e consertados: ler código sem executar é como ler uma partitura sem tocar.

As ferramentas oficiais da disciplina são o Google Planilhas, o Overleaf e o Spyder, todas gratuitas. As duas primeiras rodam no navegador e não exigem instalação; o Spyder vem junto com a distribuição Anaconda.
