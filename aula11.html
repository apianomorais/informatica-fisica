Tipos de dados e variáveis

Números, texto, lógico e as conversões entre eles. É curto e parece burocrático, mas quase todo erro de aluno iniciante nasce de um tipo que não era o que se pensava.

Agora que vocês já sabem navegar no Spyder, vamos mergulhar nos fundamentos do Python. Hoje vamos entender como o computador "pensa" sobre números, textos e outros tipos de dados.

1. Revisão rápida dos desafios

Vamos conferir os desafios da aula passada! Quem conseguiu resolver?

Exemplo 11.1: Soluções dos desafios 
# Desafio 1: Luz verde (lambda = 500 nm)
import math
c = 299792458  # m/s
lambda_verde = 500e-9  # 500 nm em metros
frequencia = c / lambda_verde
print(f"Frequência da luz verde: {frequencia:e} Hz")
print(f"Isso é {frequencia/1e14:.1f} x 10^14 Hz")

# Desafio 2: Próton em movimento (v = 0.1c)

2. Os tipos de dados fundamentais

Python trabalha com diferentes "tipos" de informação. É como ter gavetas organizadas para cada coisa!

Conceito chave Tipos de dados em Python:
  • int: Números inteiros (sem vírgula)
  • float: Números decimais (com vírgula)
  • complex: Números complexos (a + bj)
  • str: Textos (strings)
  • bool: Verdadeiro/Falso (booleanos)
Exemplo 11.2: Números inteiros (int) 
# Números inteiros - sem vírgula

print(f"Número de elétrons: {num_eletrons}")
print(f"Tipo: {type(num_eletrons)}")
print(f"Número de Avogadro: {numero_muito_grande:e}")

3. Operadores matemáticos

Vamos dominar as operações que todo físico usa!

Exemplo 11.7: Operadores básicos 
# Operações fundamentais
a = 10
b = 3

soma = a + b           # 13
subtracao = a - b      # 7
multiplicacao = a * b  # 30
divisao = a / b        # 3.333...
divisao_inteira = a // b  # 3 (só a parte inteira)
resto = a % b          # 1 (resto da divisão)
potencia = a ** b      # 1000

print(f"a = {a}, b = {b}")
print(f"a + b = {soma}")
print(f"a - b = {subtracao}")
print(f"a x b = {multiplicacao}")
print(f"a / b = {divisao:.3f}")
print(f"a / b (inteiro) = {divisao_inteira}")
print(f"a mod b = {resto}")
print(f"a^b = {potencia}")
Exemplo 11.8: Aplicações físicas importantes 
# Lei de Ohm: V = R x I
resistencia = 100  # Ohm
corrente = 0.5     # A
tensao = resistencia * corrente

print(f"Lei de Ohm: V = R x I")
print(f"V = {resistencia} x {corrente} = {tensao} V")

# Energia cinética: E = (1/2)mv2
massa = 2.5  # kg
velocidade = 10  # m/s
energia_cinetica = 0.5 * massa * velocidade**2

print(f"Energia cinética: E = (1/2)mv2")
print(f"E = (1/2) x {massa} x {velocidade}2 = {energia_cinetica} J")

# Lei dos gases ideais: PV = Nk_BT
P = 101325   # Pa (1 atm)
V = 0.0224   # m³ (1 mol de gás a CNTP)
N = 6.022e23 # partículas
k_B = 1.380649e-23  # J/K
T = P * V / (N * k_B)

print(f"Lei dos gases: PV = Nk_BT")
print(f"T = PV/Nk_B = {P} x {V} / ({N:.3e} x {k_B:.3e}) = {T:.1f} K")

4. Conversões entre tipos

Às vezes precisamos converter um tipo em outro. É como trocar as gavetas!

Exemplo 11.9: Conversões comuns 
# Conversões de tipos
numero_str = "42"
numero_int = int(numero_str)     # String para inteiro
numero_float = float(numero_str) # String para decimal

print(f"String: '{numero_str}' (tipo: {type(numero_str)})")
print(f"Inteiro: {numero_int} (tipo: {type(numero_int)})")
print(f"Float: {numero_float} (tipo: {type(numero_float)})")

# Cuidado com conversões!
pi_str = "3.14159"
pi_int = int(float(pi_str))  # Precisa converter para float primeiro!
print(f"pi como inteiro: {pi_int}")

# Booleanos para números
verdadeiro = int(True)   # 1
falso = int(False)       # 0
print(f"True = {verdadeiro}, False = {falso}")
Comandos Essenciais para Processamento de Dados em Python No processamento de dados científicos, estas funções são fundamentais:
  • split(sep) Divide uma string em uma lista de substrings usando um separador específico.
    • Parâmetro: sep (string usada como separador)
    • Retorno: Lista de strings
    • Exemplo: "a,b,c".split(",") \(\) ["a", "b", "c"]

  • len(iterável) Retorna o número de elementos em uma sequência (lista, tupla, string, etc.).

    • Exemplos:
      • len([1,2,3]) \(\) 3
      • len("Python") \(\) 6

  • for ... in ... Estrutura de repetição que itera sobre os elementos de uma sequência.

    • Sintaxe: for elemento in sequência:
    • Uso típico: Processar cada item de uma coleção
    • Exemplo: for x in [1,2,3]: print(x)

  • sum(iterável) Soma os elementos de uma sequência numérica.

    • Requisito: Elementos devem ser números
    • Exemplo: sum([1,2,3]) \(\) 6
    • Aplicação: Cálculo de totais, médias, etc.

Exemplo 11.10: Aplicação prática - lendo dados 
# Simulando leitura de dados experimentais
dados_experimento = "25.3, 24.8, 25.1, 24.9"  # Temperaturas em °C

# 1. split: converte string em lista de strings
temperaturas_str = dados_experimento.split(", ")  # ["25.3", "24.8", ...]

# 2. for loop + float(): converte cada string em número
temperaturas = []
for temp_str in temperaturas_str:
    temperaturas.append(float(temp_str))  # [25.3, 24.8, ...]

# 3. len: conta elementos (4 temperaturas)
# 4. sum: soma todos os valores
media = sum(temperaturas) / len(temperaturas)  # Cálculo da média

print(f"Temperatura média: {media:.2f} °C")  # Formata com 2 decimais
Fluxo de Processamento de Dados O exemplo mostra um fluxo típico de tratamento de dados científicos:
  1. Aquisição: Dados brutos em formato de string (ex: leitura de sensor)
  2. Separação: split() para dividir os valores
  3. Conversão: for + float() para transformar em números
  4. Análise: sum() e len() para calcular estatísticas
  5. Apresentação: Formatação de saída com f-strings
Aplicações em física:
  • Processamento de dados de sensores
  • Análise de medições repetidas
  • Cálculo de médias experimentais
  • Importação de dados de arquivos CSV

5. Formatação de números

Como apresentar resultados de forma profissional!

Exemplo 11.11: Formatação básica 
# Diferentes formas de mostrar números
numero = 1234.56789
constante_planck = 6.62607015e-34

print(f"Número original: {numero}")
print(f"2 casas decimais: {numero:.2f}")
print(f"4 casas decimais: {numero:.4f}")
print(f"Notação científica: {numero:.2e}")
print(f"Separador de milhares: {numero:,.2f}")

print(f"Constante de Planck: {constante_planck}")
print(f"Notação científica: {constante_planck:.3e}")
print(f"Formato padrão: {constante_planck:.2g}")
Função abs() e Formatação de Dados em Física A função abs() e a formatação de saída são essenciais para apresentação de resultados científicos:
  • abs(x) Retorna o valor absoluto de x (módulo do número).
    • Propósito: Calcular magnitudes sem sinal (distâncias, erros, diferenças)
    • Matematicamente: \(|x| = {cases} x & {se } x 0 \\ -x & {se } x < 0 {cases}\)
    • Aplicação: Cálculo de erros absolutos, diferenças entre valores teóricos e experimentais
    • f"{valor:.nf}": Formata com n casas decimais
    • f"{valor:,}": Adiciona separadores de milhar
    • f"{valor:.ne}": Notação científica com n dígitos
    • f"{valor:.n% }": Formata como porcentagem com n casas decimais

Exemplos práticos de formatação:
  • 1234.5678:.2f \(\) "1234.57"
  • 9876543:, \(\) "9,876,543"
  • 0.000000123:.3e \(\) "1.230e-07"
  • 0.856:.2% \(\) "85.60%"
Conceitos de análise experimental:
  • Erro absoluto: \(E_{{abs}} = |{valor medido} - {valor teórico}|\)
  • Erro percentual: \(E_{\%} = ({E_{{abs}}}{{valor teórico}}) 100\%\)
  • Aceleração da gravidade:
    • Valor padrão: \(g = 9.80665\,{m/s}^2\) (ao nível do mar)
    • Varia com altitude e latitude

Exemplo 11.12: Análise de medições experimentais 
# Medição de aceleração da gravidade
g_medido = 9.78452  # Valor obtido experimentalmente
g_teorico = 9.80665  # Valor teórico padrão

# Cálculo de erros usando abs()
erro_absoluto = abs(g_medido - g_teorico)
erro_percentual = (erro_absoluto / g_teorico) * 100

# Apresentação profissional de resultados
print("=== MEDIÇÃO DA ACELERAÇÃO DA GRAVIDADE ===")
print(f"Valor medido:    {g_medido:.5f} m/s2")  # 5 casas decimais
print(f"Valor teórico:   {g_teorico:.5f} m/s2")
print(f"Erro absoluto:   {erro_absoluto:.5f} m/s2")  # Usa abs()
print(f"Erro percentual: {erro_percentual:.3f}%")  # 3 casas decimais

# Formatação avançada para constantes físicas
velocidade_luz = 299792458
const_plank = 6.62607015e-34

print("fundamentais:")
print(f"Velocidade da luz: {velocidade_luz:,} m/s")  # Separadores de milhar
print(f"Constante de Planck: {const_plank:.3e} J.s")  # Notação científica
Boas Práticas para Resultados Científicos Ao apresentar resultados experimentais:
  • Use unidades claramente: Sempre inclua unidades nas legendas e valores
  • Erros significativos: Mostre erros absolutos e percentuais
  • Precisão adequada: Formate com casas decimais apropriadas à precisão do instrumento
  • Destaque importantes: Use cabeçalhos e separadores para organizar informações
  • Notação científica: Para valores muito grandes ou pequenos (\(>10^6\) ou \(<10^{-6}\))
Por que usar abs()?
  • Evita erros de sinal em cálculos de diferenças
  • Garante que magnitudes sejam sempre positivas
  • Fundamental para estatísticas e análise de erros
