Aula 10 · Programação em Python

Introdução ao Python e ao Spyder

A linguagem, o ambiente de trabalho e os primeiros programas. Tudo o que vem depois nesta unidade se apoia no que acontece aqui: escrever, rodar, errar e ler a mensagem de erro.

Bem-vindos ao mundo da programação científica! Hoje vocês vão descobrir por que Python se tornou a linguagem favorita dos físicos e como usar o Spyder para resolver problemas reais da Física.

1. Por que Python na Física?

Python não é apenas mais uma linguagem de programação - é a ferramenta que está revolucionando a pesquisa em Física:

Onde Python é usado em Física:

  • CERN: Análise de dados do LHC (Large Hadron Collider)
  • NASA: Processamento de imagens de telescópios espaciais
  • Gravitational waves: LIGO usa Python para detectar ondas gravitacionais
  • Astrofísica: Simulações de galáxias e estrelas
  • Física médica: Processamento de imagens de ressonância magnética
Conceito chave Por que Python?
  • Sintaxe simples e legível (parece com inglês!)
  • Bibliotecas científicas poderosas (NumPy, SciPy, Matplotlib)
  • Comunidade ativa e colaborativa
  • Gratuito e open-source
  • Integração fácil com outros programas

2. Conhecendo o Spyder

O Spyder é seu novo laboratório virtual! Vamos explorar cada ferramenta:

Os painéis principais:

  • Editor (esquerda): Onde você escreve seus programas (.py)
  • Console (canto inferior direito): Para testes rápidos e resultados
  • Variable Explorer (canto superior direito): Mostra todas suas variáveis
  • Help: Documentação na hora que precisar
  • Plots: Seus gráficos aparecerão aqui

Configurações que vocês vão querer ajustar:

  • Tema: Tools → Preferences → Appearance (escuro ou claro)
  • Fonte: Tools → Preferences → Editor → Display (tamanho confortável)
  • Layout: View → Window layouts (escolham o que preferem)
Intuição Atalhos que vão salvar suas vidas:
  • F5: Executa o programa inteiro
  • F9: Executa apenas a linha onde está o cursor
  • Ctrl+1: Comenta/descomenta linha
  • Ctrl+L: Limpa o console

3. Primeiros códigos

Hora de colocar a mão na massa! Vamos começar simples e ir evoluindo.

Console vs. Script - qual usar quando?

  • Console: Para testes rápidos, como uma calculadora
  • Script (Editor): Para programas que você quer salvar e reutilizar
O comando print() em Python O comando print() é uma função embutida que exibe informações na saída padrão (normalmente o terminal). É essencial para:
  • Depuração de código
  • Exibição de resultados
  • Interação com o usuário
  • Visualização de dados e variáveis
Parâmetros principais:
  • sep Separador entre itens (padrão: espaço)
  • end Caractere final (padrão: quebra de linha)
  • file Redireciona saída (ex: arquivo)
Exemplo 10.1: Primeiro programa 
print("Olá, Física!")
  print("Meu nome é Maria")
  print("Bem-vindos aos Métodos Numéricos!")

  # Combinando parametros
  print("Python", "é", "incrível", sep="-", end="!")
  # Saída: Python-é-incrível!
Exemplo 10.2: Python como calculadora científica 
# Operações básicas - teste no console primeiro!
  soma = 5 + 3
  produto = 4 * 7
  divisao = 15 / 4
  potencia = 2**10

  print(f"5 + 3 = {soma}")
  print(f"4 x 7 = {produto}")
  print(f"15 / 4 = {divisao}")
  print(f"2^10 = {potencia}")

  # Agora vamos usar funções matemáticas
  import math
  raiz = math.sqrt(16)
  seno = math.sin(math.pi/2)
  logaritmo = math.log10(100)

  print(f"sqrt(16) = {raiz}")
  print(f"sen(pi/2) = {seno}")
  print(f"log10(100) = {logaritmo}")
Bibliotecas em Python e o módulo math Uma biblioteca (ou módulo) em Python é uma coleção de funções e constantes pré-definidas que ampliam as capacidades da linguagem. Elas permitem:
  • Reutilização de código especializado
  • Acesso a funcionalidades avançadas
  • Organização lógica de recursos
  • Economia de tempo de desenvolvimento
O comando import é usado para carregar bibliotecas. Para matemática, o módulo math oferece:
  • math.sqrt(x) Calcula a raiz quadrada de x
  • math.sin(x) Calcula o seno de x (radianos)
  • math.log10(x) Calcula o logaritmo decimal de x
  • math.pi Constante pi (3.141592...)
Exemplo 10.3: Cálculos matemáticos básicos 
import math

  # Cálculo de hipotenusa pelo Teorema de Pitágoras
  cateto_a = 3
  cateto_b = 4
  hipotenusa = math.sqrt(cateto_a**2 + cateto_b**2)
  print(f"Hipotenusa: {hipotenusa:.2f}")  # 5.00

  # Conversão graus para radianos
  angulo_graus = 30
  angulo_rad = math.radians(angulo_graus)
  print(f"Seno de 30°: {math.sin(angulo_rad):.3f}")  # 0.500

  # Cálculo logarítmico
  ph = -math.log10(2.5e-4)
  print(f"pH da solução: {ph:.1f}")  # 3.6
Funções Matemáticas em Python (math) O módulo math fornece funções matemáticas avançadas. As principais funções usadas no exemplo são:
  • math.sqrt(x) Calcula a raiz quadrada de x.
    • Exemplo: math.sqrt(25) retorna 5.0
    • Restrição: x deve ser não-negativo

  • math.radians(x) Converte ângulo de graus para radianos.

    • Fórmula: \({radianos} = {graus} {}{180}\)
    • Exemplo: math.radians(180) retorna 3.14159... (\(\))

  • math.sin(x) Calcula o seno de x (em radianos).

    • Exemplo: math.sin(math.pi/2) retorna 1.0
    • Alternativas: math.cos(), math.tan()

  • math.log10(x) Calcula o logaritmo decimal (base 10) de x.

    • Exemplo: math.log10(1000) retorna 3.0
    • Relação com pH: \({pH} = -_{10}({concentração H}^+)\)

  • math.pi Constante matemática pi (aproximadamente 3.14159)
  • Formatação de strings Sintaxe f"{valor:.nf}" para controlar casas decimais:

    • :.2f: 2 casas decimais
    • :.3f: 3 casas decimais
    • :.1f: 1 casa decimal

Aplicações Científicas Estas funções são essenciais para:
  • Física: Cálculos de cinemática, óptica e ondulatória
  • Engenharia: Projetos estruturais e análise de tensões
  • Química: Cálculos de pH, cinética química e termodinâmica
  • Biologia: Modelagem de crescimento populacional e bioinformática
  • Estatística: Transformações de dados e modelos probabilísticos

Agora vamos resolver problemas reais de Física. Execute cada código e observe o Variable Explorer!

Exemplo 10.4: As constantes que governam o universo 
# Constantes físicas fundamentais - decorar não precisa, 
  # mas entender é fundamental!
  c = 299792458  # velocidade da luz (m/s)
  h = 6.62607015e-34  # constante de Planck (J.s)
  e = 1.602176634e-19  # carga elementar (C)
  k_B = 1.380649e-23  # constante de Boltzmann (J/K)

  print("=== CONSTANTES FÍSICAS FUNDAMENTAIS ===")
  print(f"Velocidade da luz: {c:e} m/s")
  print(f"Constante de Planck: {h:e} J*s")
  print(f"Carga elementar: {e:e} C")
  print(f"Constante de Boltzmann: {k_B:e} J/K")
Temperatura na Física: Conceitos Fundamentais A temperatura é uma grandeza física fundamental que mede o estado térmico de um sistema, relacionada à energia cinética média das partículas. Na Física, trabalhamos com três escalas principais:

EscalaSímboloReferências
Celsius°C\({cases} 0°{C} & {ponto de fusão da água} \\ 100°{C} & {ponto de ebulição da água} {cases}\)
KelvinK\({cases} 0\,{K} & {zero absoluto} \\ 273.15\,{K} & {ponto de fusão da água} {cases}\)
Fahrenheit°F\({cases} 32°{F} & {ponto de fusão da água} \\ 212°{F} & {ponto de ebulição da água} {cases}\)

Conversões fundamentais:
  • Celsius para Kelvin: \(T_K = T_C + 273.15\)
  • Kelvin para Celsius: \(T_C = T_K - 273.15\)
  • Celsius para Fahrenheit: \(T_F = {9}{5}T_C + 32\)
  • Fahrenheit para Celsius: \(T_C = {5}{9}(T_F - 32)\)
Pontos notáveis:
  • Zero absoluto: Menor temperatura possível (-273.15°C / 0 K) onde cessa o movimento molecular
  • Temperatura ambiente: 25°C (varia conforme condições climáticas)
  • Importância do Kelvin: Escala absoluta usada em leis físicas como \(PV = Nk_BT\)
Exemplo 10.5: Conversões de temperatura 
# Todo físico precisa dominar conversões de temperatura
  temp_celsius = 25  # temperatura ambiente em Juazeiro do Norte
  temp_kelvin = temp_celsius + 273.15

  print(f"Temperatura ambiente: {temp_celsius}°C = {temp_kelvin} K")

  # Outras conversões importantes
  temp_fahrenheit = temp_celsius * 9/5 + 32
  print(f"Em Fahrenheit: {temp_fahrenheit}°F")

  # Zero absoluto
  zero_absoluto_C = -273.15
  zero_absoluto_F = zero_absoluto_C * 9/5 + 32
  print(f"Zero absoluto: {zero_absoluto_C}°C = {zero_absoluto_F}°F")

  # Ponto de ebulição da água
  ebulicao_C = 100
  ebulicao_K = ebulicao_C + 273.15
  print(f"Ebulição da água: {ebulicao_C}°C = {ebulicao_K} K")
Aplicações Científicas Estas conversões são essenciais para:
  • Termodinâmica: Cálculo de eficiência de máquinas térmicas
  • Meteorologia: Análise de padrões climáticos globais
  • Criogenia: Estudo de materiais em baixíssimas temperaturas
  • Astrofísica: Caracterização de estrelas e meio interestelar
  • Química: Determinação de pontos de fusão/ebulição de substâncias
A Revolução de \(E=mc^2\): Massa e Energia A equação \(E=mc^2\), proposta por Albert Einstein em 1905, é um dos pilares da física moderna. Ela estabelece a equivalência entre massa e energia, revelando que:
  • Massa é energia concentrada: A massa de um objeto é medida por seu conteúdo energético
  • Fator de conversão: \(c^2\) é o fator de conversão entre quilogramas e joules
  • Significado de \(c\): \(c = 299\,792\,458\,{m/s}\) (velocidade da luz no vácuo)
Implicações fundamentais:
  • Um pequeno valor de massa equivale a enorme quantidade de energia (\(c^2 910^{16}\,{m}^2/{s}^2\))
  • Explica a fonte de energia das estrelas (fusão nuclear) e bombas atômicas (fissão nuclear)
  • Fundamenta a teoria da relatividade restrita
Constantes importantes no exemplo:
  • Massa do elétron: \(m_e = 9.1093835610^{-31}\,{kg}\)
  • Elétron-volt (eV): Unidade de energia usada em Física Atômica \(1\,{eV} = 1.60217663410^{-19}\,{J}\)
Exemplo 10.6: A famosa \(E=mc^2\) na prática 
# A equação mais famosa da Física!
  c = 299792458  # velocidade da luz (m/s)
  m_eletron = 9.10938356e-31  # massa do elétron (kg)

  # Energia de repouso do elétron
  E_eletron = m_eletron * c**2
  print(f"Energia de repouso do elétron: {E_eletron:e} J")

  # Vamos converter para uma unidade mais familiar: eV
  eV = 1.602176634e-19  # 1 eV em Joules
  E_eletron_eV = E_eletron / eV
  print(f"Em elétron-volts: {E_eletron_eV/1e6:.3f} MeV")

  # Quanto de energia tem em 1 grama de matéria?
  m_grama = 1e-3  # kg
  E_grama = m_grama * c**2
  print(f"Energia em 1g de matéria: {E_grama/1e15:.1f} PJ")
  print("Isso equivale à energia de 17 bombas de Hiroshima!")
Contexto Histórico e Aplicações Curiosidades:
  • Einstein publicou esta equação como corolário da Teoria da Relatividade Restrita em 1905
  • A primeira confirmação experimental veio com a medição da energia liberada em decaimentos nucleares
  • 1g de matéria contém \(2510^6\) kWh - energia para abastecer uma cidade média por um mês!
Aplicações modernas:
  • Energia nuclear: Reatores de fissão e fusão
  • Astrofísica: Processos em estrelas de nêutrons e buracos negros
  • Medicina: Tomografia por emissão de pósitrons (PET scan)
  • Partículas elementares: Produção de novas partículas em aceleradores
