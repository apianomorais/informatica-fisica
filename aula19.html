Análise de dados com Pandas

A planilha programável. Tudo o que a unidade I fez à mão no Google Planilhas, agora feito em código e com dezenas de milhares de linhas.

Hoje vamos conhecer o Pandas, a biblioteca que transformou Python na ferramenta favorita para análise de dados científicos. Se o NumPy é nossa calculadora vetorial, o Pandas é nossa planilha programável — com superpoderes!

1. Revisão rápida dos desafios

Exemplo 19.1: Soluções dos desafios da Aula 18 
import numpy as np
  import csv

  # Desafio 1: Diário de temperaturas interativo
  medicoes = []
  while True:
      entrada = input("Temperatura (graus C) [ou 'fim']: ")
      if entrada.lower() == "fim":
          break
      try:
          medicoes.append(float(entrada))
      except ValueError:
          print("  Valor invalido. Use ponto decimal.")

  if medicoes:
      with open("diario.csv", "w", newline="", encoding="utf-8") as f:
          csv.writer(f).writerows(
              [["medicao", "celsius", "kelvin"]] +
              [[i+1, t, t+273.15] for i, t in enumerate(medicoes)]
          )
      arr = np.array(medicoes)
      print(f"Salvo! Media={arr.mean():.2f} Min={arr.min():.2f} Max={arr.max():.2f}")

  # Desafio 2: Pipeline completo (calculadora de energia)
  def pipeline_energia():
      m = float(input("Massa (kg): "))
      v = float(input("Velocidade (m/s): "))
      h = float(input("Altura (m): "))
      g = 9.81
      Ec = 0.5 * m * v**2
      Ep = m * g * h
      Em = Ec + Ep

      with open("energia.txt", "w", encoding="utf-8") as f:
          f.write("# Analise de Energia Mecanica")
          f.write(f"# massa={m} kg  velocidade={v} m/s  altura={h} m")
          f.write("Ec_J  Ep_J  Em_J")
          f.write(f"{Ec:.4f}  {Ep:.4f}  {Em:.4f}")

      print(f"{'Grandeza':20s} {'Valor (J)':>12s}")
      print("-" * 33)
      for nome, val in [("Energia cinetica", Ec),
                        ("Energia potencial", Ep),
                        ("Energia mecanica", Em)]:
          print(f"{nome:20s} {val:>12.4f}")

  pipeline_energia()

2. Por que Pandas?

Conceito chave O Pandas organiza dados em estruturas tabulares chamadas DataFrame — pense em uma planilha Excel acessível por código. Ao contrário de arrays NumPy (que exigem que todos os dados sejam do mesmo tipo), DataFrames suportam colunas de tipos mistos, rótulos nomeados e operações poderosas de agrupamento e filtragem.
Exemplo 19.2: Por que Pandas em vez de NumPy para dados tabulares? 
import numpy as np
  import pandas as pd

  # Com NumPy: colunas sao acessadas por indice numerico
  dados_np = np.array([
      [1.0, 25.3, 101.2],
      [2.0, 26.1, 100.9],
      [3.0, 24.8, 101.5],
  ])
  print("NumPy - temperatura (coluna 1):", dados_np[:, 1])

  # Com Pandas: colunas tem nomes; tipos mistos sao ok
  dados_pd = pd.DataFrame({
      "experimento":    [1, 2, 3],
      "temperatura_C":  [25.3, 26.1, 24.8],
      "pressao_hPa":    [101.2, 100.9, 101.5],
      "valido":         [True, True, False],       # booleano
      "local":          ["Lab A", "Lab A", "Lab B"], # texto
  })
  print("- temperatura:")
  print(dados_pd["temperatura_C"])
  print(f": {dados_pd['temperatura_C'].mean():.2f} graus C")

3. Series e DataFrame

Estruturas fundamentais do Pandas
  • pd.Series Array 1-D com rótulos (índice). Equivale a uma coluna de tabela.
    • pd.Series(data, index=None, name=None)
    • Atributos: s.index, s.values, s.dtype, s.name

  • pd.DataFrame Tabela 2-D com rótulos de linha e coluna.

    • Criado a partir de dicionário, lista de listas, array NumPy ou arquivo.
    • Atributos: df.shape, df.columns, df.dtypes, df.index

Exemplo 19.3: Criando Series e DataFrames 
import pandas as pd
  import numpy as np

  # --- Series ---
  massas = pd.Series(
      [1.008, 4.003, 6.941, 9.012, 10.811],
      index=["H", "He", "Li", "Be", "B"],
      name="massa_atomica_u"
  )
  print("Series de massas atomicas:")
  print(massas)
  print(f"do Litio: {massas['Li']} u")
  print(f"Elementos mais pesados que 5 u:{massas[massas > 5]}")

  # --- DataFrame a partir de dicionario ---
  tabela = pd.DataFrame({
      "simbolo": ["H",  "He", "Li",     "Be",      "B"],
      "nome":    ["Hidrogenio","Helio","Litio","Berilio","Boro"],
      "Z":       [1, 2, 3, 4, 5],
      "massa_u": [1.008, 4.003, 6.941, 9.012, 10.811],
      "periodo": [1, 1, 2, 2, 2],
  })
  print("- tabela periodica parcial:")
  print(tabela)
  print(f": {tabela.shape}")
  print(f"Colunas: {list(tabela.columns)}")

4. Carregando dados experimentais

Exemplo 19.4: Lendo CSV 
import pandas as pd
  import numpy as np

  # Criando um arquivo de exemplo
  np.random.seed(42)
  t = np.linspace(0, 10, 50)
  x = 5*t + 0.5*9.81*t**2 + np.random.normal(0, 0.5, 50)
  v = 5 + 9.81*t + np.random.normal(0, 0.2, 50)

  pd.DataFrame({"tempo_s": t, "posicao_m": x, "velocidade_ms": v}).to_csv(
      "cinematica.csv", index=False, float_format="%.4f"
  )

  # Carregando
  df = pd.read_csv("cinematica.csv")
  print(f"Arquivo carregado: {df.shape[0]} linhas x {df.shape[1]} colunas")
  print("5 linhas:")
  print(df.head())
  print("3 linhas:")
  print(df.tail(3))
Parâmetros úteis de pd.read_csv()
  • sep=',' Separador de colunas (';' para padrão BR).
  • decimal='.' Separador decimal (',' para padrão BR).
  • comment='#' Ignora linhas que começam com #.
  • skiprows=n Pula as primeiras \(n\) linhas.
  • usecols=[...</b> ] Carrega apenas colunas especificadas.
  • parse_dates Converte colunas para tipo datetime.
  • encoding Codificação ('utf-8', 'latin-1').

5. Explorando o DataFrame

Exemplo 19.5: Funções de exploração essenciais 
print("=== EXPLORACAO DO DATASET ===")

  # Informacoes gerais (tipos, memoria)
  df.info()

  # Estatisticas descritivas automaticas
  print(":")
  print(df.describe().round(3))

  # Dados faltantes
  print(f"faltantes: {df.isnull().sum().sum()}")

  # Amostra aleatoria
  print("aleatoria (3 linhas):")
  print(df.sample(3, random_state=42))
Funções de exploração rápida
  • df.head(n=5) Primeiras \(n\) linhas.
  • df.tail(n=5) Últimas \(n\) linhas.
  • df.info() Tipos, contagem, uso de memória.
  • df.describe() Estatísticas: contagem, média, desvio, quartis.
  • df.shape Tupla (linhas, colunas).
  • df.isnull().sum() Conta valores faltantes por coluna.
  • df.sample(n) \(n\) linhas aleatórias.
  • df.nunique() Número de valores únicos por coluna.

6. Seleção e filtros

loc vs iloc: a diferença fundamental
  • df.loc[linhas, colunas</b> ] Indexação por rótulo (nome do índice e nome da coluna).
  • df.iloc[linhas, colunas</b> ] Indexação por posição numérica (como NumPy).
Regra prática: use loc quando souber os nomes; use iloc quando souber as posições.
Exemplo 19.6: Indexação e filtros booleanos 
# iloc: posicional (como NumPy)
  print("Primeiras 3 linhas, colunas 0 e 2:")
  print(df.iloc[:3, [0, 2]])

  # loc: por rotulo
  print("'tempo_s' e 'velocidade_ms', linhas 0-4:")
  print(df.loc[:4, ["tempo_s", "velocidade_ms"]])

  # Filtros booleanos
  fase_rapida = df[df["velocidade_ms"] > 50]
  print(f"com v > 50 m/s: {len(fase_rapida)}")

  # Multiplas condicoes com & e |
  janela = df[(df["tempo_s"] >= 3) & (df["tempo_s"] <= 6)]
  print(f"Janela 3-6 s: {len(janela)} pontos")

  # query(): sintaxe mais legivel
  rapidos = df.query("velocidade_ms > 80 and posicao_m > 300")
  print(f"v > 80 e x > 300: {len(rapidos)} pontos")

8. Agrupamento e agregação

Exemplo 19.8: groupby — estatísticas por grupos experimentais 
import pandas as pd
  import numpy as np

  np.random.seed(7)
  dados_exp = pd.DataFrame({
      "condicao":       ["A"]*30 + ["B"]*30 + ["C"]*30,
      "operador":       (["P1"]*15 + ["P2"]*15)*3,
      "temperatura_C":  np.concatenate([
          np.random.normal(20, 0.5, 30),
          np.random.normal(25, 0.8, 30),
          np.random.normal(30, 0.3, 30),
      ]),
      "resistencia_ohm": np.concatenate([
          np.random.normal(100, 2, 30),
          np.random.normal(108, 3, 30),
          np.random.normal(116, 1.5, 30),
      ]),
  })

  # Estatisticas por condicao
  print("Resistencia por condicao:")
  por_condicao = dados_exp.groupby("condicao")["resistencia_ohm"].agg(
      media="mean", desvio="std", n="count"
  ).round(3)
  print(por_condicao)

  # Tabela pivo
  print("pivo (condicao x operador):")
  pivo = dados_exp.pivot_table(
      values="resistencia_ohm",
      index="condicao",
      columns="operador",
      aggfunc="mean"
  ).round(2)
  print(pivo)

9. Dados faltantes

Tratando dados faltantes em experimentos reais Falhas de sensor, leituras fora de faixa e registros corrompidos são comuns. O Pandas usa NaN para representar valores faltantes.
  • df.isnull() Máscara booleana de faltantes.
  • df.dropna() Remove linhas com NaN.
  • df.fillna(valor) Preenche com valor fixo.
  • df.fillna(method='ffill') Preenche com valor anterior.
  • df.interpolate() Interpolação linear — ideal para séries temporais físicas.
Exemplo 19.9: Comparando estratégias de preenchimento 
import pandas as pd
  import numpy as np
  import matplotlib.pyplot as plt

  np.random.seed(3)
  t     = np.linspace(0, 4*np.pi, 80)
  sinal = np.sin(t)

  # Introduzindo falhas (10% dos pontos)
  falhas = np.random.choice(len(sinal), size=8, replace=False)
  sinal_falho = sinal.astype(float).copy()
  sinal_falho[falhas] = np.nan

  df_sensor = pd.DataFrame({"tempo_s": t, "sinal": sinal_falho})
  print(f"Falhas: {df_sensor['sinal'].isnull().sum()} pontos")

  df_sensor["ffill"]  = df_sensor["sinal"].fillna(method="ffill")
  df_sensor["interp"] = df_sensor["sinal"].interpolate(method="linear")

  # Erro quadratico medio nos pontos falhos
  for col in ["ffill", "interp"]:
      eqm = np.mean((df_sensor.loc[falhas, col] - sinal[falhas])**2)
      print(f"EQM {col:6s}: {eqm:.6f}")

  # Grafico comparativo
  fig, axes = plt.subplots(1, 2, figsize=(14, 5), sharey=True)
  for ax, col, titulo in zip(axes,
      ["ffill", "interp"],
      ["Preenchimento anterior (ffill)", "Interpolacao linear"]):
      ax.plot(df_sensor["tempo_s"], df_sensor[col], "b-", lw=1.5)
      ax.plot(df_sensor["tempo_s"], sinal, "k--", lw=1, alpha=0.5,
              label="Sinal verdadeiro")
      ax.scatter(df_sensor.loc[falhas, "tempo_s"],
                 df_sensor.loc[falhas, col],
                 color="red", s=60, zorder=5, label="Ponto tratado")
      ax.set_title(titulo); ax.set_xlabel("Tempo (s)")
      ax.legend(); ax.grid(True, alpha=0.3)
  axes[0].set_ylabel("Sinal")
  plt.tight_layout(); plt.show()

10. Pipeline completo de análise

Exemplo 19.10: Resistência elétrica em função da temperatura 
import pandas as pd
  import numpy as np
  import matplotlib.pyplot as plt

  # 1. Gerar e salvar dados brutos
  np.random.seed(99)
  T  = np.repeat(np.arange(20, 121, 10), 5)
  R  = 100 * (1 + 3.9e-3*(T - 20)) + np.random.normal(0, 0.5, len(T))
  pd.DataFrame({"T_C": T, "R_ohm": R}).to_csv(
      "resistencia_T.csv", index=False, float_format="%.3f"
  )

  # 2. Carregar e explorar
  df = pd.read_csv("resistencia_T.csv")
  print(f"Dataset: {df.shape[0]} medicoes, {df['T_C'].nunique()} temperaturas")

  # 3. Estatisticas por temperatura
  resumo = df.groupby("T_C")["R_ohm"].agg(
      media="mean", desvio="std", n="count"
  ).reset_index().round(3)

  # 4. Ajuste linear
  coef   = np.polyfit(resumo["T_C"], resumo["media"], 1)
  T_fit  = np.linspace(20, 120, 100)
  R_fit  = np.polyval(coef, T_fit)
  alpha  = coef[0] / 100
  print(f"Coeficiente de temperatura: alpha = {alpha:.2e} 1/grauC")
  print(f"(Literatura para cobre: alpha = 3.9e-3 1/grauC)")

  # 5. Grafico profissional
  fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))

  ax1.scatter(df["T_C"], df["R_ohm"], alpha=0.35, s=15,
              color="steelblue", label="Medicoes")
  ax1.errorbar(resumo["T_C"], resumo["media"], yerr=resumo["desvio"],
               fmt="ro", capsize=4, label="Media +/- desvio")
  ax1.plot(T_fit, R_fit, "k--", lw=2, label="Ajuste linear")
  ax1.set_xlabel("Temperatura (graus C)"); ax1.set_ylabel("Resistencia (Ohm)")
  ax1.set_title("R(T) - Dados e Ajuste"); ax1.legend(); ax1.grid(True, alpha=0.3)

  residuos = resumo["media"] - np.polyval(coef, resumo["T_C"])
  ax2.bar(resumo["T_C"], residuos, width=4, color="coral", alpha=0.7)
  ax2.axhline(0, color="k", lw=1)
  ax2.set_xlabel("Temperatura (graus C)"); ax2.set_ylabel("Residuo (Ohm)")
  ax2.set_title("Residuos do Ajuste"); ax2.grid(True, alpha=0.3)

  plt.tight_layout(); plt.show()

  # 6. Exportar relatorio
  resumo.to_csv("relatorio_resistencia.csv", index=False)

Conceito chave Novos conceitos que vocês dominam:
  • pd.Series e pd.DataFrame — estruturas fundamentais
  • pd.read_csv() e df.to_csv() — I/O de dados
  • df.head(), df.info(), df.describe() — exploração

Intuição Quando usar Pandas vs NumPy?
  • NumPy: dados puramente numéricos, matrizes, álgebra linear, máxima performance.
  • Pandas: dados tabulares com colunas nomeadas, tipos mistos, grupos, datas.
  • Na prática, usamos os dois juntos: Pandas para organizar, NumPy/SciPy para calcular.
