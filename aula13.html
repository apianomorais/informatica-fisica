Estrutura Condicional if em Python O comando if é fundamental para controle de fluxo em programas, permitindo executar blocos de código condicionalmente. Sua sintaxe básica é: 
if condição:
      # bloco executado se condição for True
  elif outra_condição:  # opcional
      # bloco executado se outra_condição for True
  else:  # opcional
      # bloco executado se nenhuma condição anterior for True
Componentes essenciais:
  • Condição: Expressão que avalia para True ou False
  • Indentação: Define os blocos de código (4 espaços recomendados)
  • Operadores de comparação: ==, !=, >, <, >=, <=
  • Operadores lógicos: and, or, not

Exemplo 5.4: Aplicações avançadas de if em funções científicas 
def avaliar_experimento(dados, limite_inferior, limite_superior, nome="experimento"):
      """Analisa dados experimentais com verificações de validade"""
    
      # Verificação de segurança dos dados
      if not isinstance(dados, list):
          print("Erro: Dados devem ser uma lista")
          return None
        
      if len(dados) == 0:
          print("Aviso: Nenhum dado fornecido")
          return None
    
      # Pré-processamento (remove outliers)
      dados_validos = []
      for valor in dados:
          if limite_inferior <= valor <= limite_superior:
              dados_validos.append(valor)
          else:
              print(f"Valor {valor} fora dos limites aceitáveis")
    
      # Análise estatística condicional
      if len(dados_validos) >= 5:  # Mínimo para estatística confiável
          media = sum(dados_validos) / len(dados_validos)
          desvio = (sum((x-media)**2 for x in dados_validos)/len(dados_validos))**0.5
        
          print(f"=== Resultados para {nome} ===")
          print(f"Amostras válidas: {len(dados_validos)}/{len(dados)}")
          print(f"Média: {media:.2f} ± {desvio:.2f}")
        
          if desvio > media * 0.2:
              print("ALERTA: Alta variabilidade nos dados!")
          elif desvio > media * 0.1:
              print("OBS: Variabilidade moderada")
          else:
              print("Variabilidade dentro do esperado")
        
          return {"media": media, "desvio": desvio}
      else:
          print("Dados insuficientes para análise (mínimo 5 valores válidos)")
          return None

  # Testando com dados de pH
  dados_ph = [7.1, 7.3, 6.8, 7.5, 8.2, 6.5, 7.8, 5.9, 7.2, 7.4]
  resultado = avaliar_experimento(dados_ph, 6.0, 8.0, "níveis de pH")

  # Teste com dados inválidos
  dados_invalidos = [10.2, 4.5, "texto", None]
  avaliar_experimento(dados_invalidos, 0, 10, "dados inválidos")
Padrões de Uso Científico do if Aplicações comuns em análise de dados:
  • Validação de entrada: Verificar tipo e formato dos dados
  • Controle de qualidade: Filtrar valores fora de faixa aceitável
  • Análise de tendências: Classificar resultados em categorias
  • Proteção contra erros: Evitar divisões por zero ou operações inválidas
  • Seleção de algoritmos: Escolher método de cálculo baseado nos dados
Boas práticas:
  • Use if not lista em vez de if len(lista) == 0 para verificar listas vazias
  • Para múltiplas condições complexas, considere funções separadas
  • Documente sempre as condições de contorno
  • Prefira condições positivas (if valido) em vez de negativas (if not invalido)

Exemplo Físico: Lei de Ohm com Verificações 
def lei_de_ohm(V=None, I=None, R=None):
      """Calcula a grandeza ausente na lei de Ohm com verificações"""
      if sum(x is not None for x in [V, I, R]) != 2:
          print("Erro: Forneça exatamente duas grandezas")
          return None
    
      try:
          if V is None:
              return I * R
          elif I is None:
              return V / R if R != 0 else None
          elif R is None:
              return V / I if I != 0 else None
      except TypeError:
          print("Erro: Valores devem ser numéricos")
          return None

  # Testes
  print("Resistência:", lei_de_ohm(V=12, I=0.5))  # 24 ohms
  print("Tensão:", lei_de_ohm(I=0.1, R=100))     # 10 volts
  print("Corrente:", lei_de_ohm(V=9, R=300))     # 0.03 amps
  print("Caso inválido:", lei_de_ohm(V=12))      # Erro

4. Escopo de variáveis

Onde as variáveis "vivem" e podem ser acessadas?

Exemplo 5.8: Variáveis locais vs globais 
# Variável global
  contador_global = 0
  nome_programa = "Sistema de Análise"

  def incrementar_contador():
      """Tenta modificar contador global"""
      global contador_global  # Precisa declarar como global!
      contador_global += 1
      print(f"Contador agora é: {contador_global}")

  def mostrar_info():
      """Acessa variável global (só leitura)"""
      print(f"Programa: {nome_programa}")
      print(f"Contador atual: {contador_global}")

  def exemplo_local():
      """Demonstra variáveis locais"""
      variavel_local = "Só existe aqui dentro!"
      numero_local = 42
    
      print(f"Dentro da função: {variavel_local}")
      print(f"Número local: {numero_local}")

  # Testando
  print("=== Teste de Escopo ===")
  mostrar_info()
  incrementar_contador()
  incrementar_contador()
  exemplo_local()

  # Esta linha daria erro - variavel_local não existe aqui!
  # print(variavel_local)  # NameError!

  print(f"Contador final: {contador_global}")
Intuição Regras de escopo:
  • Variáveis locais: existem apenas dentro da função
  • Variáveis globais: existem em todo o programa
  • Para modificar global: use global nome_variavel
  • Python procura: local → global → built-in

Bibliotecas random e string em Python As bibliotecas random e string fornecem ferramentas essenciais para geração de valores aleatórios e manipulação de strings.
  • string - Constantes úteis para strings
    • ascii-letters: Contém todas as letras ASCII (a-z e A-Z)
    • digits: Contém dígitos de 0 a 9
    • punctuation: Contém caracteres de pontuação/símbolos
    • ascii-lowercase: Letras minúsculas (a-z)
    • ascii-uppercase: Letras maiúsculas (A-Z)

  • random - Geração de números aleatórios

    • choice(sequência): Escolhe um elemento aleatório da sequência
    • randint(a, b): Inteiro aleatório entre a e b (inclusive)
    • shuffle(lista): Embaralha a lista in-place
    • sample(sequência, k): Amostra k elementos únicos
    • random(): Float aleatório entre 0.0 e 1.0

Exemplo 5.10: Gerador Avançado de Senhas Seguras 
import random
  import string

  def gerar_senha_segura(tamanho=12, usar_numeros=True, usar_simbolos=True, usar_maiusculas=True):
      """Gera senhas seguras com garantia de caracteres mínimos de cada tipo"""
    
      # Definindo conjuntos de caracteres
      minusculas = string.ascii_lowercase
      maiusculas = string.ascii_uppercase if usar_maiusculas else ""
      numeros = string.digits if usar_numeros else ""
      simbolos = string.punctuation if usar_simbolos else ""
    
      # Garantindo pelo menos um caractere de cada tipo selecionado
      senha = []
      if usar_maiusculas:
          senha.append(random.choice(maiusculas))
      if usar_numeros:
          senha.append(random.choice(numeros))
      if usar_simbolos:
          senha.append(random.choice(simbolos))
    
      # Completando o restante da senha
      todos_caracteres = minusculas + maiusculas + numeros + simbolos
      for _ in range(tamanho - len(senha)):
          senha.append(random.choice(todos_caracteres))
    
      # Embaralhando para não ter padrão previsível
      random.shuffle(senha)
    
      return ''.join(senha)

  # Testando o gerador avançado
  print("=== SENHAS SEGURAS ===")
  print(f"Básica: {gerar_senha_segura(8, True, False, False)}")
  print(f"Forte: {gerar_senha_segura(12, True, True, True)}")
  print(f"Máxima segurança: {gerar_senha_segura(16, True, True, True)}")

  # Gerar senha com requisitos específicos
  print("para sistema financeiro:")
  print(gerar_senha_segura(10, True, True, True))
Boas Práticas para Gerar Senhas Seguras Para criar geradores de senhas realmente seguros:
  • Garanta diversidade: Inclua pelo menos um caractere de cada tipo
  • Use tamanho adequado: Mínimo de 12 caracteres para segurança
  • Embaralhe sempre: Evite padrões previsíveis
  • Evite ambiguidade: Remova caracteres similares (1, l, I, 0, O)
  • Use secrets: Para aplicações críticas, prefira o módulo secrets
Exemplo de remoção de caracteres ambíguos: 
caracteres_seguros = (

Segurança: random vs secrets Para aplicações de segurança:
  • random: Adequado para fins gerais não-críticos
    • Usa algoritmo pseudo-aleatório (previsível com semente conhecida)
    • Bom para simulações e jogos

  • secrets: Deve ser usado para criptografia e segurança

    • Gera números verdadeiramente aleatórios (usa fontes do SO)
    • Fornece token_hex, token_urlsafe para tokens seguros
    • Recomendado para senhas, chaves de autenticação, CSRF tokens

Exemplo 5.11: Validador de CPF - algoritmo simplificado 
def validar_cpf_simples(cpf):
      """Validação básica de CPF (apenas formato e tamanho)"""
    
      # Remover pontos e traços
      cpf_numeros = cpf.replace(".", "").replace("-", "")
    
      # Verificar se tem 11 dígitos
      if len(cpf_numeros) != 11:
          return False
    
      # Verificar se todos são dígitos
      if not cpf_numeros.isdigit():
          return False
    
      # Verificar se não são todos iguais (111.111.111-11, etc.)
      if cpf_numeros == cpf_numeros[0] * 11:
          return False
    
      return True

  def formatar_cpf(cpf):
      """Formata CPF no padrão XXX.XXX.XXX-XX"""
      cpf_numeros = cpf.replace(".", "").replace("-", "")
      if len(cpf_numeros) == 11:
          return f"{cpf_numeros[:3]}.{cpf_numeros[3:6]}.{cpf_numeros[6:9]}-{cpf_numeros[9:]}"
      return cpf

  # Testando
  cpfs_teste = [
      "12345678901",
      "111.111.111-11",
      "123.456.789-01",
      "12345678",
      "123abc45678"
  ]

  print("=== VALIDADOR DE CPF ===")
  for cpf in cpfs_teste:
      valido = validar_cpf_simples(cpf)

Exemplo 5.12: Sistema de notas e média 
def calcular_media_ponderada(notas, pesos):
      """Calcula média ponderada dado notas e seus pesos"""
      if len(notas) != len(pesos):
          return "Erro: Número de notas e pesos deve ser igual!"
    
      soma_produtos = 0
      soma_pesos = 0
    
      for nota, peso in zip(notas, pesos):
          soma_produtos += nota * peso
          soma_pesos += peso
    
      if soma_pesos == 0:
          return "Erro: Soma dos pesos não pode ser zero!"
    
      return soma_produtos / soma_pesos

  def determinar_situacao(media, nota_minima=7.0):
      """Determina situação do aluno baseada na média"""
      if media >= nota_minima:
          return "APROVADO"
      elif media >= nota_minima * 0.6:  # 60% da nota mínima
          return "RECUPERAÇÃO"
      else:
          return "REPROVADO"

  def relatorio_aluno(nome, notas, pesos=None):
      """Gera relatório completo do aluno"""
      print(f"=== RELATÓRIO: {nome.upper()} ===")
    
      if pesos is None:
          # Média simples
          media = sum(notas) / len(notas)
          print("Tipo: Média Simples")
      else:
          # Média ponderada
          media = calcular_media_ponderada(notas, pesos)
          print("Tipo: Média Ponderada")
          if isinstance(media, str):  # Se retornou erro
              print(f"Erro: {media}")
              return
    
      situacao = determinar_situacao(media)
    
      print(f"Notas: {notas}")
      if pesos:
          print(f"Pesos: {pesos}")
      print(f"Média: {media:.2f}")
      print(f"Situação: {situacao}")
    
      # Dica motivacional
      if situacao == "APROVADO":
          print("Parabéns! Continue assim!")
      elif situacao == "RECUPERAÇÃO":
          print("Quase lá! Estude mais um pouco.")
      else:
          print("Não desista! Você consegue melhorar!")

  # Testando o sistema
  alunos = [

  for nome, notas in alunos:
      relatorio_aluno(nome, notas)

Exemplo 5.13: Jogo da velha - funções para organizar o código 
def criar_tabuleiro():
      """Cria um tabuleiro vazio 3x3"""
      return [[" " for _ in range(3)] for _ in range(3)]

  def mostrar_tabuleiro(tabuleiro):
      """Exibe o tabuleiro na tela"""
      print("0   1   2")
      for i in range(3):
          print(f"{i}  {tabuleiro[i][0]} | {tabuleiro[i][1]} | {tabuleiro[i][2]} ")
          if i < 2:
              print("  -----------")

  def fazer_jogada(tabuleiro, linha, coluna, jogador):
      """Faz uma jogada no tabuleiro"""
      if tabuleiro[linha][coluna] == " ":
          tabuleiro[linha][coluna] = jogador
          return True
      return False

  def verificar_vitoria(tabuleiro, jogador):
      """Verifica se o jogador ganhou"""
      # Verificar linhas
      for linha in tabuleiro:
          if all(casa == jogador for casa in linha):
              return True
    
      # Verificar colunas
      for col in range(3):
          if all(tabuleiro[linha][col] == jogador for linha in range(3)):
              return True
    
      # Verificar diagonais
      if all(tabuleiro[i][i] == jogador for i in range(3)):
          return True
      if all(tabuleiro[i][2-i] == jogador for i in range(3)):
          return True
    
      return False

  def tabuleiro_cheio(tabuleiro):
      """Verifica se o tabuleiro está cheio"""
      for linha in tabuleiro:
          if " " in linha:
              return False
      return True

  # Simulação de algumas jogadas
  print("=== JOGO DA VELHA - SIMULAÇÃO ===")
  tabuleiro = criar_tabuleiro()

  # Simulando uma partida
  jogadas = [
      (1, 1, "X"),  # X no centro
      (0, 0, "O"),  # O no canto
      (1, 0, "X"),  # X na lateral
      (2, 2, "O"),  # O no canto oposto
      (1, 2, "X"),  # X completa a linha do meio
  ]

  for linha, coluna, jogador in jogadas:
      fazer_jogada(tabuleiro, linha, coluna, jogador)
      mostrar_tabuleiro(tabuleiro)
    
      if verificar_vitoria(tabuleiro, jogador):
          print(f"Jogador {jogador} GANHOU!")
          break
      elif tabuleiro_cheio(tabuleiro):
          print("EMPATE!")
          break
    
      print(f"{jogador} jogou na posição ({linha}, {coluna})")

Exemplo 5.14: Documentando funções adequadamente 
def calcular_imc(peso, altura):
      """
      Calcula o Índice de Massa Corporal (IMC).
    
      Parâmetros:
          peso (float): Peso da pessoa em quilogramas
          altura (float): Altura da pessoa em metros
    
      Retorna:
          float: Valor do IMC calculado
        
      Exemplo:
          >>> calcular_imc(70, 1.75)
          22.86
      """
      if altura <= 0:
          raise ValueError("Altura deve ser maior que zero")
      if peso <= 0:
          raise ValueError("Peso deve ser maior que zero")
    
      imc = peso / (altura ** 2)
      return round(imc, 2)

  def classificar_imc(imc):
      """
      Classifica o IMC segundo padrões da OMS.
    
      Parâmetros:
          imc (float): Valor do Índice de Massa Corporal
    
      Retorna:
          str: Classificação do IMC
      """
      if imc < 18.5:
          return "Abaixo do peso"
      elif imc < 25:
          return "Peso normal"
      elif imc < 30:
          return "Sobrepeso"
      else:
          return "Obesidade"

  def relatorio_saude(nome, peso, altura):
      """
      Gera relatório completo de saúde baseado no IMC.
    
      Parâmetros:
          nome (str): Nome da pessoa
          peso (float): Peso em kg
          altura (float): Altura em metros
      """
      try:
          imc = calcular_imc(peso, altura)
          classificacao = classificar_imc(imc)
        
          print(f"=== RELATÓRIO DE SAÚDE: {nome.upper()} ===")
          print(f"Peso: {peso} kg")
          print(f"Altura: {altura} m")
          print(f"IMC: {imc}")
          print(f"Classificação: {classificacao}")
        
          # Dicas baseadas na classificação
          if "normal" in classificacao.lower():
              print("Seu peso está na faixa ideal!")
          else:
              print("Considere consultar um profissional de saúde.")
            
      except ValueError as erro:
          print(f"Erro: {erro}")

  # Testando
  pessoas = [
      ("Ana", 65, 1.70),
      ("Bruno", 80, 1.80),
      ("Carlos", 90, 1.75),
      ("Diana", 55, 1.65)
  ]

  for nome, peso, altura in pessoas:
      relatorio_saude(nome, peso, altura)
Conceito chave Boas práticas para funções:
  • Nome descritivo: função deve ter nome claro sobre o que faz
  • Uma responsabilidade: cada função deve fazer apenas uma coisa
  • Documentação: sempre inclua docstring explicando a função
  • Parâmetros claros: nomes de parâmetros devem ser autoexplicativos
  • Retorno consistente: sempre retorne o mesmo tipo de dado
  • Tratamento de erros: valide entradas e trate casos especiais

Dicas

Fundamentação Teórica - Exercício 1: Conversor de Unidades Conceitos Físicos Envolvidos:
  • Sistemas de Unidades: Diferenças entre SI (metro, kg) e sistema imperial (pés, libras)
  • Conversão de Distância: \(1\ \text{m} = 3.28084\ \text{pés}\)
  • Conversão de Massa: \(1\ \text{kg} = 2.20462\ \text{lb}\)
  • Escalas Termométricas: \(K = °C + 273.15\) (zero absoluto = 0K)
Implementação Recomendada:
  • Funções puras (sem efeitos colaterais)
  • Constantes para fatores de conversão
  • Arredondamento para 2-4 casas decimais
  • Tratamento de valores negativos (exceto Kelvin)
Fundamentação Teórica - Exercício 2: Calculadora de Juros Matemática Financeira:
  • Juros Simples: \(J = C \cdot i \cdot t\)
    • Linear no tempo
    • Apenas sobre capital inicial

  • Juros Compostos: \(M = C \cdot (1 + i)^t\)

    • Crescimento exponencial
    • "Juros sobre juros"

Parâmetros Essenciais:
  • \(C\) = Capital inicial
  • \(i\) = Taxa de juros (decimal)
  • \(t\) = Tempo/períodos
  • \(J\) = Juros acumulados
  • \(M\) = Montante final
Comparação: Para \(t>1\), compostos \(>\) simples. Exemplo com \(C=1000\), \(i=0.1\):
